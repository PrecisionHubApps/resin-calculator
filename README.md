# 💧 Epoxy Resin Volume Calculator

A lightweight, privacy-focused web utility designed to help makers, artists, and DIY enthusiasts estimate the exact amount of Epoxy Resin needed for projects.

**[🚀 Launch Live Tool](https://PrecisionHubApps.github.io/resin-calculator/)**

---

## 📖 About
Resin is expensive. Guessing the volume leads to wasted materials or ruined projects. This tool calculates precise volume requirements for standard mold shapes and automatically breaks down the mixture into Part A (Resin) and Part B (Hardener).

## ✨ Features
* **Dual Shape Engine:** Supports both Rectangular (tables, trays) and Circular (coasters, art) calculations.
* **Smart Buffering:** Automatically calculates a **5% waste buffer** to ensure you don't run short during a pour.
* **Mixing Logic:** Breaks down total volume based on a standard **1:1 Mixing Ratio**.
* **Privacy First:** No data is sent to any server. All calculations happen locally in the user's browser.
* **Responsive:** Works perfectly on mobile devices for use in the workshop.

## 🛠️ Installation & Usage
If you want to run this locally or modify the code:

1.  Clone the repository:
    ```bash
    git clone [https://github.com/PrecisionHubApps/resin-calculator.git](https://github.com/PrecisionHubApps/resin-calculator.git)
    ```
2.  Navigate to the folder:
    ```bash
    cd resin-calculator
    ```
3.  Open `index.html` in any web browser.
